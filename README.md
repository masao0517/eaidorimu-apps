# eaidorimu-apps

えーあいどりーむ（e-aidori-mu）のiPhoneアプリのサポートページとプライバシーポリシーを置く公開サイト。Vercelで配信（https://eaidorimu-apps.vercel.app/）。更新は `vercel deploy --prod --yes` で反映。GitHub Pagesは使わない（URLにユーザー名が入るため）。

- `index.html` … アプリ一覧
- `<アプリ名>/index.html` … サポートページ
- `<アプリ名>/privacy.html` … プライバシーポリシー

アプリ本体のソースはここには置かない。
